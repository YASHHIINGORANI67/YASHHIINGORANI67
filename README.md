## Currently building: AegisRisk

**Status: In development — not yet a published or independently validated application.**

AegisRisk is a Python portfolio risk management project developed through an iterative coding workflow. The prototype explores portfolio valuation, allocation, concentration, hypothetical stress scenarios and risk-aware decision support.

**Planned next steps:** integrate historical market data, implement and validate VaR/Expected Shortfall, develop visual analytics, add automated tests and publish reproducible application documentation.
